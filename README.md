# sec-exhibits-ner

NER (Named Entity Recognition) analysis of SEC Exhibit 10 filings to systematically identify contract parties and relationship specifics.

## Setup

Requires Python (Anaconda recommended). See `environment.yml` for dependencies.

## Project Structure

```
├── CLAUDE.md              # Instructions for Claude Code AI assistant
├── .claude/               # Claude Code configuration (skills, hooks, settings)
├── inputs/                # Raw input data / filings
├── outputs/               # Processed results
├── notebooks/             # Jupyter notebooks for analysis
└── src/                   # Python source code
```
